INSTALLATION DE TOOTH_DENTAIRE
==============================

1. Si Python n'est pas installe sur ce poste, telecharger
   "Windows installer (64-bit)" sur https://www.python.org/downloads/windows/
   et placer le fichier (python-3.x.x-amd64.exe) dans ce dossier.

2. (Facultatif) Pour reprendre une base existante, placer stock.db dans ce
   dossier. Elle n'ecrase jamais une base deja installee.

3. Double-cliquer sur Installer.bat et suivre les questions
   (dossier propose : C:\tooth_dentaire).

A la fin :
- l'outil est dans le dossier choisi, avec Lancer.bat et l'installateur Python ;
- un raccourci "tooth_dentaire" est sur le Bureau ;
- ce dossier d'installation est supprime (il est garde en cas d'erreur).

Reinstaller ou mettre a jour : relancer un nouveau dossier d'installation vers
le meme dossier. Le code est remplace, les donnees (donnees\stock.db) restent.

Au premier lancement, Windows demande d'autoriser Python dans le pare-feu :
accepter pour les reseaux prives.
